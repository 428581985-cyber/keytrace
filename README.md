# KeyTrace

> 采集你在真实工作里的每一次击键，算出打字训练器看不到的瓶颈，并生成针对性的练习材料。

**状态：早期开发中，尚无可用版本。** 仓库里目前只有方案文档，代码从「物理击键采集」开始写。

---

## 为什么做

keybr 这类自适应训练器有三个盲区：

1. **只在练习题里测** —— 你在微信、Word、浏览器里真实打了什么、错在哪，它看不见
2. **只练英文字母** —— 中文、数字、符号、组合键一律没有，而这些占了真实输入的一半以上
3. **只有绝对数字** —— 它不会告诉你「`z` 你错了 17%，而你一天只按了 8 次这个键」

KeyTrace 的做法：在**本地**记录真实击键（含中文上屏），归因出「哪次是打错、哪次是改措辞」，再按你的弱点生成练习词表。

关键差异在于**中文**：练中文打字练的是**拼音字母**，不是汉字。所以中文词库按拼音串筛选——想练 `z`，就抽「在 / 做 / 最 / 走」。

## 会做什么（规划中）

| 模块 | 说明 |
| --- | --- |
| 采集 | 全局物理击键（Raw Input）+ 上屏文本（UI Automation），记录前台应用 |
| 归因 | 区分打错 / 改措辞；区分拼音层错误 / 选字层错误 |
| 画像 | 每个键的置信度，输出弱点 Top 5 |
| 词库 | 英文按字母、中文按拼音、符号单独一套，可直接导入 keybr / monkeytype |
| 看板 | 单文件 HTML，离线可看，双击就开 |
| 导出 | 转成 keybr 等工具的格式；这是留给社区的扩展口，欢迎新增格式 |

## 隐私

- **所有数据只存在本地，不联网**
- 默认按需录制（热键开关），不常驻后台
- 内置排除列表（密码管理器、银行客户端等）
- 源码完全公开，你可以自己审计、自己编译

> **请注意**：这类工具的行为特征与键盘记录器一致，会被 Defender 等安全软件标记。这不是误报，是这类功能的固有代价。请自行判断是否信任。
